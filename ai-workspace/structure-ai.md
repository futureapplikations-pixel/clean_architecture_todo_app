
# File Overview

| File Path                                                  | Purpose                                                                      |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `lib/main.dart`                                            | The entry point of the application.                                          |
| `lib/presentation/app.dart`                                | The root widget of the application.                                          |
| `lib/presentation/router.dart`                             | Defines the routes of the application using `go_router`.                     |
| `lib/presentation/theme.dart`                              | Defines the theme of the application.                                        |
| `lib/presentation/view/memento_list.dart`                  | Displays a list of mementos.                                                 |
| `lib/presentation/view/memento_form.dart`                  | A form for creating and editing mementos.                                    |
| `lib/presentation/view/search_memento_list.dart`           | A view for searching mementos.                                               |
| `lib/presentation/widgets/memento_card.dart`               | A card that displays a single memento.                                       |
| `lib/domain/model/memento.dart`                            | The data model for a memento.                                                |
| `lib/domain/repository/mementos.dart`                      | An abstract repository for mementos.                                         |
| `lib/data/repository/mementos_impl.dart`                   | The implementation of the mementos repository.                               |
| `lib/domain/usecase/create_todo.dart`                      | A use case for creating a memento.                                           |
| `lib/domain/usecase/delete_completed_todos.dart`           | A use case for deleting completed mementos.                                  |
| `lib/domain/usecase/delete_todo.dart`                      | A use case for deleting a memento.                                           |
| `lib/domain/usecase/get_todo_list.dart`                    | A use case for getting a list of mementos.                                   |
| `lib/domain/usecase/search_todo_list.dart`                 | A use case for searching mementos.                                           |
